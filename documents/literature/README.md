# Literature

Use this folder to convert papers, repos, blog posts, and aggregate projects into structured evidence.

## Subfolders

- `paper-notes/`: one note per paper or project.
- `source-maps/`: maps from aggregate projects, survey posts, or repo bibliographies to underlying primary sources.

## Priority Sources

Initial targets:

- Lottery Ticket Hypothesis and follow-on work
- Early-bird tickets
- Dynamic sparse training
- OpenMythos cited sources
- Recurrent-depth and looped Transformer papers
- Low-precision and optimizer-state reduction papers
- Data filtering, curriculum, and synthetic reasoning data papers

Prefer primary sources over commentary whenever possible.
