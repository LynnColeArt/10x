# Literature

Use this folder to convert papers, repos, blog posts, and aggregate projects into structured evidence.

## Subfolders

- `paper-notes/`: one note per paper or project.
- `source-maps/`: maps from aggregate projects, survey posts, or repo bibliographies to underlying primary sources.

## Working Docs

- [seed-bibliography.md](seed-bibliography.md): first-pass source corpus across sparse training, recurrent depth, data efficiency, optimizer/memory work, conditional compute, and baseline calibration.
- [non-obvious-search-map.md](non-obvious-search-map.md): lateral search strategy for creative, non-mainstream research seams.
- [replication-chatter/](replication-chatter/README.md): public reproduction discussions, repo issues, and practitioner landmines.

## Priority Sources

Initial targets:

- Lottery Ticket Hypothesis and follow-on work
- Early-bird tickets
- Dynamic sparse training
- OpenMythos cited sources
- Recurrent-depth and looped Transformer papers
- Low-precision and optimizer-state reduction papers

Prefer primary sources over commentary whenever possible.
