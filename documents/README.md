# Documents

This folder is the working memory for the R&D effort.

## Structure

- [research-strategy.md](research-strategy.md): project framing, research lanes, evidence rules, and milestones.
- [literature/](literature/): paper intake, source maps, and claim extraction.
- [synthesis/](synthesis/): cross-paper matrices, compatibility analysis, and candidate training recipes.
- [experiments/](experiments/): experiment cards, baselines, evaluation plans, and run notes.
- [hardware/](hardware/): hardware profiles, constraints, memory budgets, and runbook notes.
- [decisions/](decisions/): durable project decisions and scope boundaries.
- [artifacts/](artifacts/): generated outputs, exported tables, plots, and other non-source research artifacts.

## Current North Star

Find at least one credible, reproducible path to `10x+` effective training efficiency for reasoning-capable small language models, without hiding the cost in unavailable teacher models, degraded evaluations, or unrealistic hardware assumptions.
